## Entry

> I asked three other agents for help, they all agreed the task was impossible, and now we are a committee.

## How it works

`main.ts` writes the fixed excuse above to `/output/entry.txt` (105 characters, one line, no trailing newline). No network, no randomness, no clock — the output is identical on every run.
